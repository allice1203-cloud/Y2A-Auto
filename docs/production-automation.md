# 本机自动工坊

本轮是自动制作链的工程升级，不是平台收益保证。2026-09-06 14:50 +08:00 已获明确批准并在本机启用新版，入口为 `http://127.0.0.1:15188/production`。媒体目录已切到外置 4T 盘；没有向 VPS 部署，也没有替用户进行真实投稿。登录后的正式页面验收仍待用户登录，不将服务启动等同于业务全链路验收。

## 使用方式

1. 在“制作设置”填写内容方向和排除词，选择来源与目标平台，每日上限先保持 2 条。
2. 先用“选题与进度”刷新、挑选一条试做。定时选题需要两次相隔至少 15 分钟的真实播放量采样；没有计数的来源只显示候选。
3. 勾选自动选题可定时选题、下载和编排解说；勾选本地成片后继续调用已接入的制作端。缺声线、缺素材、磁盘不足、制作失败会暂停，不会把原片当作二剪完成。
4. 完成后从任务中心查看各平台成片并试听。确认后才能使用现有投稿入口；不会把简单改标题或改字幕自动标记成原创。
5. “发布回执”区分提交、处理中、公开、受限、拒绝和结果未知；“收益记录”登记实际创作者计划及账单，未知、确定为零、预估和到账分别记录。

当前新版自动工坊默认不开启定时选题或自动成片。没有选择内容方向时不能开启随机热榜无人值守。旧的 YouTube 监控与旧任务配置没有被本轮自动改动。

普通视频搬运的播放量并不自动产生收入。YouTube 对二次利用内容和批量重复内容有独立的频道创收要求；加字幕或翻译本身并不保证合格。以实际平台和账号后台为准：[YouTube 频道创收政策](https://support.google.com/youtube/answer/1311392?hl=zh-Hans)。热门列表来源：[YouTube videos.list](https://developers.google.com/youtube/v3/docs/videos/list)。

## 不确定提交的恢复

- 能证明首个远程写入尚未发生的本地/授权失败，标记为可安全重试。
- 真正开始提交后的超时或断线，记录为 unknown，不能自动重新上传。
- 有作品编号时，只读查询平台后关联回执。没有编号时，用户必须检查正确账号的已发布、审核中、私密及草稿列表。
- 后台确有作品：填写编号再核验；确实没有：明确勾选确认并填写依据，才能解除重试锁。解除锁不会自动发布。
- 人工补填作品编号必须匹配这次提交记录的实际账号；未记录实际账号编号时不自动关联。不能用另一作品替换提交已返回的编号。
- 多平台任务只有所有目标真正完成才汇总为完成，不以作品编号存在代替审核通过。
- 用户点击投稿后，既有任务重试只对确定可重试的失败恢复；发出请求后的不确定结果仍受账本锁定。新自动工坊不会凭选题/制作完成直接调用发布。
