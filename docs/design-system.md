# 视频搬运通道 v0.5 设计系统

## 产品气质

视频搬运通道是内容运营工作台，不是营销落地页。界面遵循四个原则：

1. 内容判断优先于装饰；
2. 关键状态必须一眼可读；
3. 高风险发布动作必须保持清晰边界；
4. 桌面端保持专业密度，移动端保持完整可操作。

## 视觉基础

- 导航底色：`#0c1020`
- 页面底色：`#f4f5f9`
- 主表面：`#ffffff`
- 主文字：`#171a2b`
- 次级文字：`#6e7489`
- 分割线：`#e5e7ee`
- 主信号色：`#655cf6`
- 成功状态：`#24b184`
- 警告状态：`#d29a2c`
- 危险状态：`#df5c67`

字体优先使用 Apple 系统字体与苹方，标题采用紧凑字距，控件使用明确的字号和字重，
不依赖浏览器默认样式。

## 布局系统

- 桌面端使用 `242px` 固定工作台导航和弹性内容画布。
- 核心内容最大宽度为 `1360px`。
- 首页使用一个深色内容指挥面板、一个状态轨道和一个最近动态工作区。
- 搬运中心使用页面引导、指标轨道、平台状态带、规则工作区、快速搬运面板和任务区。
- 设置、任务、审核和监控页面复用同一应用壳层、表单、表格与弹窗语言。
- `991px` 以下切换为抽屉导航；`767px` 以下操作区和数据轨道纵向重排。

## 组件约束

- 页面只允许一个视觉焦点，避免重复的渐变卡片和装饰徽章。
- 指标使用开放式分隔轨道，不拆成大量孤立卡片。
- 平台连接状态使用统一圆点和文字，不用大面积语义色。
- 主按钮只用于下一步主操作，次要操作保持白底细边框。
- 空状态使用媒体信号和时间线几何，不使用卡通插画。
- 所有动效必须支持 `prefers-reduced-motion`。

## 维护要求

- 修改全局壳层时同时验证首页、搬运中心、任务、审核、监控和设置。
- 每次视觉发布至少检查桌面端和 `390 × 844` 移动端。
- 新增页面优先复用 `page-intro`、`metric-rail`、`workspace-panel` 和现有表单组件。
- 修改静态样式后更新 `base.html` 中的 CSS 版本查询参数，避免公网缓存旧样式。
